# <center> **natrium_Na** </center>
### <center> спортивные соревнования дома и в офисе </center>

Pet-проект **Python**. 

Разработан для лёгких спортивных соревнований дома в семейном кругу, в офисе в кругу коллег, для тёплых встреч с друзьями.
Пока что в арсенале лишь один вид спорта: дартс. 
В перспективе будут ещё виды спорта. 
В обозримой перспективе будет добавлен кикер (настольный футбол).

---
### Описание
Программа представляет собой информационное поле с состоянием спортивного соревнования в текущем режиме. Состояние динамически меняется по мере происходящих спортивных событий. Все участники соревнований и зрители могут наблюдать за спортивной драмой в режиме реального времени.

Помимо информационного поля, имеются поля для внесения новых данных.

### Ход соревнований:
* Регистрация участников

Открывается окно, где вносятся данные участников (уникальный номер, имя, фамилия, что представляет участник - населённый пункт, отдел компании и т.п.). По мере внесения данных, в этом же окне формируется список участников соревнований.

* Квалификация

Открывается окно, в котором можно по уникальному номеру участника принудительно или по порядку (с помощью кнопки "следующий ?") вызывать конкретного участника для 5-ти серий из 3-х бросков. После каждой серии текущее состояние спортивного соревнования меняется в реальном времени. По итогам квалификации в полуфинал выходят 10 лучших участников.

* Полуфинал

Открывается окно с результатами 10-ти лучших участников. На этом этапе принудительно выбрать участника для бросков нельзя, потому что их последовательность будет с 1-го места до 10-го.

* Финал

Открывается окно с результатами полуфинала. В финале происходит всё так же, как и в полуфинале, за ислючением последовательности. Начинается финал с 10-го места и последним для бросков выходит лидер полуфинала. Это сделано намеренно для густой спортивной драмы и развязки в самом конце.
